- **Risk/investigation:** LOW for isolated containment styling; MEDIUM if render structure/imports change. Reproduce Ember at Arabic/English narrow widths with motion on/off, inspect which box exceeds viewport, and separate fixture/tooling problems from CSS. Root cause is Not verifiable without reproduction; existing clipping is not permission for another global overflow rule.
- **Plan/allowed scope:** no patch now. If reproduced later, fix only the demonstrated owning rule, preserve sticky navigation/focus and other themes; add meaningful regression evidence rather than hiding page-wide overflow.
- **Expected verification:** application baseline plus exact before/after scroll bounds, sticky navigation, keyboard/RTL/reduced-motion and adjacent-design checks. Browser harness route coverage is not an executed pass here.
- **Rollback/evidence gap:** revert only the owner-local patch if it clips content or breaks sticky/focus behavior. Reproduction and runtime checks Not run; defect/root cause/fix Not verifiable. **Documentation walkthrough: Passed; implementation not performed.**
